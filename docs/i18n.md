# Translating the UI (i18n)

MarketLink ships in 10 languages. English is the source; a key missing in another language shows in English.
Settings → Language (and the footer switcher) picks one; the default is English, or the browser language on a first visit.

| Code | Language | Code | Language |
|---|---|---|---|
| `en` | English (source) | `fr` | Français |
| `vi` | Tiếng Việt | `es` | Español |
| `zh` | 中文（简体） | `de` | Deutsch |
| `ja` | 日本語 | `th` | ไทย |
| `ko` | 한국어 | `id` | Bahasa Indonesia |

## Where strings live

- `frontend/src/locales/<lng>/<Namespace>.json` — one namespace per page folder (`pages/CustomerCart` →
  `CustomerCart.json`), plus `common.json` for everything under `components/`, `layout/`, `constants/`, `utils/`.
- `frontend/src/i18n/resources.ts` lists the English files; they also type every key, so `tsc` fails on a key that
  does not exist in English.

## Writing a page

```tsx
import { useTranslation } from 'react-i18next';

const CartPage = () => {
  const { t } = useTranslation('CustomerCart');
  return (
    <>
      <h1>{t('title')}</h1>
      <p>{t('split', { count: stalls })}</p>              {/* plurals: split_one / split_other */}
      <p>{t('cutoff', { time: formatTime(cutoff) })}</p>  {/* interpolation: {{time}} */}
    </>
  );
};
```

- Strings inside links or bold text: use `<Trans t={t} i18nKey="…" components={{ b: <b />, link: <Link to="…" /> }} />`
  with `<b>…</b>` / `<link>…</link>` in the JSON. Never split one sentence into several keys.
- Constants outside a component (option lists, table headers): keep the key in the constant, call `t()` when rendering.
- Keys are short camelCase names grouped by section (`empty.title`, `summary.total`), not the English sentence.
- Every language file has the same keys as English. Plurals: `_one` and `_other` (languages without plural forms —
  vi, zh, ja, ko, th, id — may only need `_other`, but keep `_one` too so the file mirrors English).

## Numbers, money, dates, units

Always go through `src/lib/format.ts`; it follows Settings (language, date format, clock, currency, kg/lb):
`vnd`, `perUnit(price, unit)`, `unitPrice`, `units(count, unit)`, `unitName(unit)`, `formatDate`, `formatDayMonth`,
`formatTime`, `formatClock('07:00')`, `dayName(dow)`, `weekday(date)`, `dayList(days)`. No hand-written "Mon", "07:00"
or "/ kg" in a component.

## What is not translated

- Demo data in `src/data/` (market, stall, product, people names, sample reviews) — it stands for what the server sends.
- Messages the server sends in `message` / field errors: shown as they come (English) until the backend translates them.
- Vietnamese proper nouns keep their diacritics in every language (Vườn Cô Tư, Thảo Điền).

## Tone per language

Short, plain, "you"-addressed, like the English. Use the polite everyday register of each language (vi: "bạn";
ja: です/ます; ko: 해요체; de: "Sie"; fr: "vous"; es: "tú" is fine for a consumer app; th: polite without ครับ/ค่ะ in labels;
zh/id: neutral). Buttons are verbs. Translations are machine-assisted: a native speaker should read them before release.
