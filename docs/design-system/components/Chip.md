# Chip

Toggle chip for filtering by category, price and availability (FR-021).

- The consumer passes `children`, `selected`, `count` (result count, optional), `onClick`. The chip uses `aria-pressed`.
- A selected chip shows a check mark, not just a color change. If the group allows only one value, consider `DayChips` (radio) instead.
