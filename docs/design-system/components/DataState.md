# DataState

The three no-data states of every screen: `loading` (skeleton), `empty` (hand-lettered title + a suggestion + one action), `error` (with Try again). Covers FR-084.

- The consumer passes `kind`, `title`, `text`, `action`.
- Write the specific situation ("No stalls are selling on Thursday"), never a generic "No data".
