# OrderStatus

Order status badge for exactly the 6 states in D-04: `placed`, `accepted`, `ready`, `completed`, `declined`, `cancelled`.

- The consumer passes `status`. Pass `label` to change the wording, e.g. "Waiting for you" on the Farmer dashboard.
- Every state has its own glyph plus a word; `cancelled` is also struck through. Never rely on color to tell states apart.
