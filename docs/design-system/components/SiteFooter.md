# SiteFooter

The footer on `board`: a sitemap (FR-085), links to About Us / Contact Us / Feedback, and the OSM attribution line (required by the OSM license).

- The consumer can pass `columns: [[heading, [links…]], …]`; otherwise the default set is used.
- Always keep the line "Pay the Farmer directly at pickup" so people understand there is no online payment.
