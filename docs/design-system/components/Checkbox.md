# Checkbox

Multi-select box. Used when a Farmer picks the markets and days they sell (FR-060), for accepting terms, and for selecting several table rows.

- The consumer passes `label`, `hint`, and the input props (`checked`/`defaultChecked`, `onChange`, `disabled`, `name`, `value`).
- If only one option may be chosen, use `DayChips` or a radio instead.
