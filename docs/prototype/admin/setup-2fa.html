Set up two-step verification

Mandatory right after an admin's first sign-in (FR-008). Same three steps as admin/security.html's enrolment (scan QR / enter manual key, confirm the six-digit code, save the recovery codes), on its own page with the AdminAuthShell frame — no dashboard chrome until this is done. An admin who later turns this off from Security and wants it back on is sent back to this same page. Built directly in TSX (frontend/src/pages/admin/Setup2FA), matching how admin/security.html's own enrolment flow works.
